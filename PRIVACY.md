# Privacy

**Super Paste is local-first. What you copy stays on your Mac unless you turn on a feature that sends it somewhere,
and the two features that can are off by default.**

## What Super Paste does not do

- **No accounts.** There is nothing to sign up for.
- **No analytics or telemetry.** Super Paste never tracks usage, never sends crash reports, never phones home.
- **No servers.** The project operates none; there is nowhere for your clipboard to go.
- **No screen or keyboard access.** The Accessibility permission is used for one thing: sending ⌘V to the app in
  front when you paste. Super Paste never reads the screen and never listens to keystrokes.

## What is never saved

- Anything copied in a password manager. The built-in list: Apple Passwords, Keychain Access, 1Password (all
  versions), LastPass, Dashlane, Bitwarden, Enpass, RoboForm, Keeper, NordPass. Edit it in **Settings → Privacy →
  Ignore Applications**; add any app you like.
- Content an app marks as confidential or temporary: `org.nspasteboard.ConcealedType` (what password fields use),
  `org.nspasteboard.TransientType`, `org.nspasteboard.AutoGeneratedType` and a few older equivalents. Both filters can
  be turned off in Settings → Privacy if an app you use marks things wrongly.
- Anything copied while capturing is paused (Pause ▸ in the menu bar menu, ⌘T).

## Data inventory: what stays on your Mac

| Data | Where | Notes |
|---|---|---|
| Clipboard history and pinboards | `~/Library/Application Support/Super Paste/clips.sqlite` | Items, their pasteboard representations' metadata, titles, source app and device, pin assignments, full-text index |
| Images, files and other copied content | `~/Library/Application Support/Super Paste/Blobs` | Content-addressed by SHA-256; files copied in Finder are stored as paths and, for thumbnails, their rendered preview |
| Link previews | In `clips.sqlite` and `Blobs` | The page title, icon and preview image fetched for a copied link (see below) |
| Sync state (not your data) | `~/Library/Application Support/Super Paste/Sync` | Which records have been written and read |
| Connected MCP clients | `~/Library/Application Support/Super Paste/MCP` | Registrations and **token hashes only** |
| A damaged database, if one was ever set aside | `~/Library/Application Support/Super Paste/Backup` | |
| Settings | `~/Library/Preferences/com.udsy.superpaste.plist` | Including the ignore list and shortcuts |
| The sync encryption key | macOS Keychain, this Mac only | Leaves only when you Export Key |
| Logs | Apple's unified logging (`com.udsy.superpaste`) | Never written to a file by Super Paste; never include clipboard contents |

Nothing is stored anywhere else, and nothing in this table is uploaded by Super Paste.

## What can reach the network

| Feature | Default | What it calls | What is sent |
|---|---|---|---|
| Install updates automatically (**Settings → About**) | **On** | `api.github.com` for this project's latest release, a minute after launch and then every six hours while Super Paste runs (never more often than every four); `github.com` and GitHub's download servers only when a newer version exists | One anonymous HTTPS request with a `SuperPaste/<version>` User-Agent. No cookies, no clipboard content, no identifiers. |
| Generate Link Previews (**Settings → Privacy**) | **On** | The web page of a link you copied, through Apple's LinkPresentation | The same request a browser makes to open the page. Some links are one-time or tracked: turn this off if that matters to you. |
| Folder sync (**Settings → Sync**) | Off | Only the folder you choose (iCloud Drive, Dropbox, a network share…) | Your history and pinboards, encrypted on this Mac before they are written |
| MCP server (**Settings → Integrations**) | Off | Nothing: it listens on `127.0.0.1` only, for apps on this Mac | The items and pinboards that a client you approved asks for. What that client does with them (an assistant sending them to its provider, say) is up to the client. |

With updates and link previews off and sync and MCP left off, Super Paste works fully offline.

## Updates

Super Paste keeps itself up to date without asking. When GitHub has a newer release of `udsy19/super-paste`, it
downloads `SuperPaste.dmg` and only uses it if:

- its SHA-256 matches the one published in the release notes,
- the app inside passes a strict code-signature check and satisfies the designated requirement of the copy you run
  (it is signed with the same identity),
- it is Super Paste (`com.udsy.superpaste`) and the version the release advertises.

The verified copy waits next to the app and goes in when you quit, or sooner when your Mac has been idle for ten
minutes with the strip closed and no Paste Stack open: Super Paste then quits and reopens in the background. The
previous version goes to the Trash. Anything that fails is logged and tried again later; you are never interrupted.

Turn off **Settings → About → Install updates automatically** to stop the checks and downloads. You can still update
with the one-line installer or the DMG.

## Sync

Sync is off until you turn it on and choose a folder. Records and content are sealed with AES-256-GCM under subkeys
derived (HKDF-SHA256) from a 256-bit key generated on your Mac, and file names in the folder are keyed hashes, so
nothing in the folder is readable or even recognisable without the key. Anyone who can read the folder sees only
ciphertext; anyone with the folder **and** your exported key can read your history, so keep the key file private
and move it between Macs directly (AirDrop, a USB stick), never through the sync folder.

## MCP

The MCP server is off until you enable it, binds to `127.0.0.1` only, and refuses requests from web pages and other
hosts. A client can connect only after you approve it on Super Paste's consent page, or when you add it by hand with
a token, which is shown once and stored only as a hash. Connected clients are listed in **Settings → Integrations**
with when they last called; disconnect any of them there. Tools never write to your system clipboard. The full
security model is in [SECURITY.md](SECURITY.md); every tool is documented in [docs/MCP.md](docs/MCP.md).

## Permissions

| Permission | Needed for | If you decline |
|---|---|---|
| Accessibility | Pasting straight into the app in front (Paste Items → To active app) | Items are copied to the clipboard and you press ⌘V yourself |
| Open at login (login item) | Starting Super Paste when you log in | Open it yourself |

No other permission is requested. Super Paste reads the pasteboard the way every clipboard manager does, by polling
`NSPasteboard.general` for changes; macOS doesn't gate that behind a permission.

## Removing everything

Run `curl -fsSL https://udsy19.github.io/super-paste/install.sh | bash -s -- --uninstall`, then delete
`~/Library/Application Support/Super Paste` and `~/Library/Preferences/com.udsy.superpaste.plist`. If you used sync,
also delete the Super Paste data in your sync folder. The sync key stays in the macOS Keychain so that turning sync
back on keeps working; to remove it too, delete the `com.udsy.superpaste` item in Keychain Access.
